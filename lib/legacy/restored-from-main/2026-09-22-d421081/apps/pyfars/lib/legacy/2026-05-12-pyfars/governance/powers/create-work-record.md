Admits the holder to create a new file under `work/`.
Covers: objectives, campaigns, milestones, goals, tasks, references, implementation guides.

## Attached duties

- `consult-predwork-before-encoding` fires before any use of this power.

## Does not cover

- Modifying existing work records (separate power: `modify-work-record`).
- Creating governance records (separate power: `create-governance-record`).
