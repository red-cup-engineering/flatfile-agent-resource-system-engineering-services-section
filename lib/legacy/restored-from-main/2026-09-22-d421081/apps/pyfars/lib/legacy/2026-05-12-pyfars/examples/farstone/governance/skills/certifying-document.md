---
name: "Certifying document"
description: "Records-clerk action that certifies a document as a true copy of a public record, signing and filing the certificate. Use whenever a citizen or agency requests a certified copy of an official record."
---


## Requirements

- The original document must be a public record on file
- Records-clerk authority
- The requestor's identity (for the receipt)

## Steps

1. Locate the original record.
2. Generate a certified copy with the records-clerk's signature stamp.
3. File the certification under `operations/certifications/<receipt-slug>.md`.
4. Issue the receipt to the requestor.

## Outcomes

The certification record exists; the requestor has a certified copy; a witness fires for audit.
