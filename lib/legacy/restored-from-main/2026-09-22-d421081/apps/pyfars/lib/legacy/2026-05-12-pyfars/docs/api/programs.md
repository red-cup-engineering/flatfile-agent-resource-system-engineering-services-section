# Programs — program-frame classes

A *program* is a process executing FARS operators on a system.
The classes in `pyfars.programs` are the substrate's concrete program- frame surface — from the abstract `Program` base through the long-running `EngineProgram` down to one-shot enactments like `ScriptProgram`.
