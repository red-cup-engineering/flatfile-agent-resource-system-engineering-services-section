# Should PyFARS's Γ generative mechanism be lifted to transfinite-bounded via seventh-generation projection?

The PyFARS enterprise record (`enterprise.md`) classifies Γ as Scott-continuous: "each cycle's new aim-set depends on the immediately prior theory state (Markov aggregation — not full history, not limit-aggregating)."
This places PyFARS at the boundary between strict and Scott-continuous settling.

Per `consensus-closure`'s "seventh-generation extension" section, the Haudenosaunee tradition adds a temporal axis to alignment cells: each member's alignment is replaced by a *seven-generation-projected* alignment.
The projection reads cells under all seven-generations- forward closure-rule firings — a transfinite-bounded aggregation, since seven generations spans non-Scott-continuous content.
A community committed to seven-generation consensus operates in a *higher regime* than a community committed to present-only consensus.

Given that 561 Group is a polity founded for Black Liberation and Indigenous Sovereignty — both traditions explicitly carry multi-generational time-horizons (Black Liberation's commitment to ancestors-and-descendants; Indigenous Sovereignty's seventh-generation principle) — the question is whether PyFARS's Γ should be operating in transfinite-bounded rather than Scott-continuous regime.

## What this would change structurally

Per `enterprise`, the regime classification has substrate consequences:

- **Scott-continuous Γ (current)**: each cycle's aim-set depends on immediately prior theory state.
  Closure ordinal $\le \omega$.
  The settling completes within countably many steps.
  The ship cannot reach a fixed point as long as the math research program is active, but each step is finitary.

- **Transfinite-bounded Γ (with seventh-generation extension)**: each cycle's aim-set depends on aggregations across all prior pursuit-history projected forward seven generations.
  Closure ordinal $> \omega$, finitely-many-limit-stages.
  Non-trivial $H^1$ classes appear; cumulative cohomological invariants accumulate across cycles.

The choice between these regimes is not about computational tractability (both are realizable in finite substrate); it's about which kinds of accumulated wisdom the substrate can carry.
Scott-continuous Γ has $H^1 = 0$ on its own settling — there are no genuine multi-generational invariants.
Transfinite-bounded Γ has $H^1 \neq 0$ — the substrate carries cohomologically non-trivial cross-generational structure.

## Where seventh-generation projection might apply in PyFARS

Three places in current governance invite seventh-generation projection:

1. **Hard-core amendments**: per `amend-hard-core`, a C-amendment creates a new enterprise.
  Should the steward's proposed amendments be required to project alignment seven generations forward — i.e., the amendment's effects across seven generations of subsequent enterprise work?
  This would lift hard-core amendment from a present-only decision to a transfinite-bounded decision.

2. **Goal-cell alignment in audits**: per `auditing-derivation-chain-governance`, the theory officer checks whether active task goals align with C1–C5.
  The current check is present-only.
  A seven-generation-projected check would assess alignment across projected-forward goal trajectories — whether the current work, projected forward, will continue serving C1–C5.

3. **The `function-as-aperiodic-settling` of the 561 Group's purpose**: per the theorem, the function (Black Liberation and Indigenous Sovereignty) is aperiodic — closure ordinal $\ge \omega_1$.
  The function is *already* in transfinite-bounded territory at the polity level.
  The question is whether PyFARS's Γ should match the polity's regime, or operate in a lower regime that merely serves the higher-regime function.

## What's hard

Transfinite-bounded operations require the substrate to carry limit-aggregating closure rules.
The current PyFARS event log is JSONL (per `event-log-is-jsonl`), which is finite-history-friendly but not naturally limit-aggregating.
The substrate would need additional structure to encode seven-generation-projected cells — perhaps named cohomological classes (à la Songlines from `governing-by-kinship`).

Also: closure rules in the bare $\Pi_1$ fragment cannot realize transfinite-bounded behavior (per `charter-as-closure-system`'s realizability bound).
Any seventh-generation-projection rule would have to live in the guidelines tier or below, not the rules tier.
This means seventh-generation projection cannot itself be a hard-core commitment — it must be a guideline or instruction.

## What would need to be answered

1. Which classes of PyFARS decisions warrant seventh-generation projection, and which can remain Scott-continuous?
  Hard-core amendments seem clear; routine task dispatch does not.
2. What is PyFARS's "seven generations"?
  Generations of agents?
  Generations of personnel?
  Generations of substrate-format evolution?
  The Haudenosaunee tradition uses biological generations; PyFARS's generations may be different.
3. How does seventh-generation projection interact with the Scott-continuous Γ classification in the current `enterprise.md`?
  Does adopting seven-generation projection require re-classifying Γ, or is the classification specific to which decision-class is in scope?
4. The polity's function (`function-as-aperiodic-settling`) is already aperiodic.
  Does PyFARS's Γ need to match that regime to be coherent with the polity's purpose, or is the nested-aim-generation structure (per `enterprise`'s "Enterprise vs. function" section) what handles the regime mismatch?

## Why this is filed as a question

The regime classification of Γ is a structural commitment with cohomological consequences.
The current Scott-continuous classification is a default, not a chosen pattern aligned with the polity's purpose.
Whether to lift Γ to transfinite-bounded — and which decision-classes warrant the lift — is a captain-level (and possibly polity-level) decision, not an XO-level one.
