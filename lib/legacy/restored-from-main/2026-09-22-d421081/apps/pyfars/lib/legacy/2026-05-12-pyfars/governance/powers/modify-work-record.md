Admits the holder to edit the frontmatter or body of an existing file under `work/`.
Covers objectives, campaigns, milestones, goals, tasks, references, implementation guides.

## Attached duties

`consult-predwork-before-encoding` fires before any use of this power.

## Does not cover

- Creating new work records (separate power: `create-work-record`).
- Modifying governance records (separate power: `modify-governance-record`).
