## Description

The current `tools/platform/pyfars/src/pyfars/harnesses/repo-instructions/` harness owns four projection targets at once (`CLAUDE.md`, `AGENTS.md`, `README.md`, `replit.md`).
Per the [`harness`](../../../concepts/harness.md) concept, a harness is one substrate-projection point.
The existing harness violates that by bundling four runtimes' projections under one name.
Split:

- **`claude-code-instructions/`** (new) — owns `CLAUDE.md`.
  Sister to the existing `claude-code`, `claude-code-hooks`, `claude-code-mcp`, `claude-agent-sdk-plugin` family.
- **`agentic/`** (new) — owns `AGENTS.md` per the multi-vendor convention (Codex, Cursor, Aider, Cline, …).
  Cross-runtime.
- **`replit-instructions/`** (new) — owns `replit.md`.
  Sister to the existing `replit` (skills) and `replit-config` (config) harnesses.
- **`repository/`** (new) — owns `README.md` and `.gitignore`.
  Platform-agnostic repo files.

For each new harness:

1. Create the directory under `tools/platform/pyfars/src/pyfars/harnesses/<harness>/`.
2. Author its `_index.md` with `kind: harness`, `type: harness`, `slug: harness:<harness>`, `target-default: "."
  `, `target-runtime: <runtime-name>`.
  Body: what it writes, the substrate context it sees, run/uninstall commands.
3. Add a `templates/` subdirectory and move the relevant `.j2` file(s) from `repo-instructions/templates/` into it.
  (Template content rewrite is a separate task — this task is the structural move.)

In `tools/platform/pyfars/src/pyfars/cli/install_harness.py`:

1. Rename `_install_repo_instructions` to `_install_orientation_harness` (or similar), parameterized by harness name and the list of `(target-relative-path, template-name)` pairs that harness owns.
2. Add four entries to `_INSTALL_DISPATCH` and `_UNINSTALL_DISPATCH` (or whatever the registry tables are named): `claude-code-instructions`, `agentic`, `replit-instructions`, `repository`.
3. Remove the `repo-instructions` entries from those tables.
4. Update the module docstring (`"""``pyfars install-harness`` — install (or uninstall) a PyFARS harness."""
  `) and the `# ---------- repo-instructions harness ----------` section comment to name the new harnesses.
5. Update `claude-code/_index.md`'s note about CLAUDE.md (currently: "is generated by the `repo-instructions` harness"); change to point at `claude-code-instructions`.

Delete `tools/platform/pyfars/src/pyfars/harnesses/repo-instructions/` entirely.
